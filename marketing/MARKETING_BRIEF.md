# Inventory MCP Server — Marketing Brief (seed for a Marketing project)

## Who it is for
Shopify merchants and developers who use AI assistants and want trustworthy stock forecasts.

## One-line promise
"Ask your AI assistant what you'll run out of — and get numbers it can't make up."

## Positioning
- Open source, read-only, bring your own token: runs on your machine.
- Deterministic math with an auditable formula; the model only explains.
- Funnel: GitHub/MCP directories → Agent Forecast app.

## Claim guardrails
- Never promise accuracy or sales lift; forecasts are estimates from your own history.
- Say clearly it is read-only and where the token lives.
- Do not compare against named competitors without checking their current features.

## Proof assets (once shipped)
- A 30-second clip of an assistant answering with tool-returned numbers.
- A screenshot of `explain_forecast_inputs` output.

## Launch checklist
- [x] Public GitHub repo (`shopify-inventory-mcp`)
- [ ] README token steps tested by someone else
- [ ] Demo clip (30s)
- [ ] Directory listing — ask owner before listing
- [ ] Owner approves any social post
